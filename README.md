# La Cartelera que Suma — SINTRACAD Magdalena

Sitio web estático para la cartelera virtual de reconocimiento de SINTRACAD Subdirectiva Magdalena.

## Publicación con GitHub Pages

Los archivos que deben quedar en la raíz del repositorio son:

- `index.html`
- `.nojekyll`
- `README.md`

En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
